# Spectrum Atlas

The public front door of the Δ-probed IR pipeline: which molecules the pipeline lists, computes, anchors and validates, with the status ladder,
harmonic frequencies, depictions, and the provenance of every number.

This repository holds the **built static site** served by GitHub Pages at <https://thebreadishard.github.io/spectrum-atlas/>. The source
(export scripts, Astro site, design, backlog) lives in the project repository:
<https://github.com/thebreadishard/udacity-capstone-plan/tree/master/website>.
