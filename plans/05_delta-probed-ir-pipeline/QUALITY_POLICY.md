# Quality policy for plan 05 code

*Agreed 21 September 2026 (the user: "Akkoord"). Applies to everything under `plans/05_delta-probed-ir-pipeline/`.
Changes to this policy are dated and committed like everything else.*

## Why

Between 14 and 21 September 2026 the work produced one scientific defect (a diagnostic that read exactly degenerate
vibrations in a rotated basis) and about ten operational ones (a script emptied before its checks ran, a launch with a
SyntaxError, a cache key changed by an explicitly written default, a watcher that counted the wrong files). All were
seen and fixed. None reached the code that will be published, because that code did not exist yet. This policy is
written before the first line of it, so that quality is a property of the pipeline and not a clean-up before submission.

## Two tiers

| | **Tier 1 — probes** (`probes/`, `modules/*/`, scratch) | **Tier 2 — the package** (`src/dpir/`, `tests/`) |
|---|---|---|
| Purpose | answer one question fast; may be rough; may be thrown away | the label factory, the ΔH model, the spectrum pipeline, anything that ships or is cited |
| Must | compile-check (`python -m compileall`), one dry run, a provenance header on every result file (git hash, command, versions, machine) | everything in tier 1, plus: tests with known answers, invariance tests, type hints and docstrings, ruff clean, review by someone who did not write it, green CI |
| Enters git | yes, with the results it produced (the results are the measurement) | only through the promotion gate below |
| Runs in CI | compile-check only | ruff + the fast test suite on every push |

Code moves from tier 1 to tier 2 by **promotion**, never by copying. Promotion is the moment quality is added.

## Promotion gate (checklist, all boxes, no exceptions)

1. **Pure functions.** The computation is split into functions with explicit inputs and outputs; I/O and the command line
   are a thin layer on top.
2. **Known-answer tests.** At least one closed-form or literature value (Morse oscillator, H₂ rotational constant, …)
   and at least one real data set committed under `probes/results_*` (water, benzene T2) with its expected numbers
   pinned to the print precision of the report they appeared in.
3. **Invariance tests.** Every derived quantity has its second route or symmetry partner asserted in a test: two
   finite-difference routes agree on a model potential to round-off, degenerate partners are equal, translations and
   rotations do not change the result, atom permutation does not change the result where applicable.
4. **Negative control.** The defect that motivated the promotion (if any) is a test that fails without the fix.
5. **Reproduction of the probe's arrays.** The package reproduces the probe's committed arrays on the committed data set
   within round-off (`rtol 1e-8`), so the numbers already in documents stay traceable. The comparison is made on
   convention-free quantities (frequencies, fundamentals, constants as multisets of magnitudes): mode signs and the order
   inside degenerate pairs are conventions, and the package fixes them itself so that a report is identical on every
   machine (first CI run, 21 Sep 2026: Linux numpy chose other signs and pair orders than Windows numpy).
6. **Provenance.** Every result file ends with `dpir.provenance.provenance_block()`.
7. **Review.** A second pass by a reader who did not write the change, with this checklist and the diff only, written
   down in the commit message or the pull request. For code that goes public, one external reader.
8. **CI green** on the pull request or the commit.

## Enforcement

- **The gate is mechanical.** Nothing enters `src/dpir/` without the checklist and green CI. If it has to run today,
  it runs as a probe.
- **Every incident becomes a guard.** Each mistake recorded in the obstacle ledger produces, within a week, one of:
  a test, a tool that makes the mistake impossible, or a dated line saying why neither is worth it. The weekly slot for
  this is the Monday desk half-hour; the table below is its record.
- **Publication freeze.** Before any submission: a fresh clone on a clean machine (a Hetzner server, not the laptop),
  every number in the manuscript regenerated by script and audited (`probes/check_reading_copy_numbers.py` and its
  successors), an external code review, a tagged release archived on Zenodo with a DOI and a licence. A reproduction
  that fails means the work is not finished.
- **Local hooks.** `pre-commit install` once per clone (`.pre-commit-config.yaml` at the repository root): ruff on
  tier-2 code, syntax check on every staged Python file, a size limit of 1.5 MB per file, and a path guard that refuses
  run scratch (`psi4.out`, `*.out`, `corpus/molecules/`, `*.clean`, `timer.dat`). `git add -A` is still possible; the
  path guard makes it harmless.

## Local setup

```bash
pip install -e "plans/05_delta-probed-ir-pipeline[dev]"
pre-commit install
cd plans/05_delta-probed-ir-pipeline && pytest -m "not slow"
```

The fast suite (synthetic + committed data) runs in well under a minute and touches no electronic-structure code, so it
never competes with a running job. Tests marked `slow` run psi4 or pyscf and are started by hand.

### Review record, 21 September 2026 (first promotion)

The second reader found, and the promotion then repaired: (1) the package built degenerate pairs from groups of exactly two
while the probe took neighbours pairwise (different for a triply degenerate group) — made identical to the probe;
(2) a mode below ≈ 22 cm⁻¹ or an imaginary mode was dropped silently and its files overwrote another mode's Hessians —
now `ValueError`, as are a duplicate file and a missing partner; (3) linear molecules were projected wrongly without
notice — now `NotImplementedError`; (4) the harmonic test built its Hessian with the package's own projector (a
self-consistent error would pass) — the external vectors are now written out independently in the test; (5) no
translation/rotation/permutation invariance test — added; (6) route labels a/b could be swapped unnoticed — a
one-entry perturbation test pins them; (7) water χ_ij, Coriolis and denominators had no known answer — pinned against
pyVPT2 0.1.2 on the same Hessians to 1e-5 cm⁻¹ (agreement measured at 1e-7); (8) data tests skipped when the set was
absent, so CI could be green vacuously — `DPIR_REQUIRE_DATA=1` in CI turns a missing set into a failure, and the T2 set
is committed.

**Open, carried as guards in the table above:** `symmetry_average` averages φ_aa,jj over every j including members of another
degenerate pair, so for pair × pair blocks the result depends on pair order (the partner sum, hence the fundamentals, is
preserved; χ_sym pair × pair entries are not). Kept identical to the probe for this promotion so that the committed numbers
stay bit-for-bit; the fix is a separate tested change that re-pins the benzene arrays.
