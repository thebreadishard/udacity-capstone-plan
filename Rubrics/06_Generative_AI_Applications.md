# Project Overview

## Overview

In this project, you will design, implement, and evaluate a small-scale generative AI system using the generative modeling techniques you developed in your Nanodegree. You will choose a generative task and dataset, build and run a generative model, examine the quality and behavior of the generated outputs, and reflect on ethical considerations such as bias, misuse, or creative ownership.

This project uses only the tools you already know:

* Python
* NumPy
* Pandas
* PyTorch
* Matplotlib / Seaborn
* Jupyter Notebooks

You are building and running generative models in this project. The focus is on correct implementation, thoughtful evaluation of generated outputs, and responsible reasoning rather than producing polished or production-ready generations.

## Why This Project Matters

Generative AI systems introduce unique technical and ethical challenges beyond traditional predictive modeling. Employers expect professionals to:

* Implement generative models correctly using established architectures
* Understand how training data influences generated outputs
* Evaluate output quality using appropriate qualitative and quantitative approaches
* Recognize risks related to bias, misuse, hallucination, or creative ownership
* Communicate limitations and responsible-use considerations clearly
* Connect technical design decisions to ethical implications

This project develops the applied judgment required to work responsibly with generative systems and prepares you for advanced generative and agentic AI work later in the capstone.

## What You Will Build

You will create:

* A Jupyter Notebook (generative\_ai.ipynb) that:
* loads and preprocesses a dataset appropriate for generative modeling
* implements and runs a generative model (GAN, VAE, diffusion model, or Transformer-based text or image generation)
* generates sample outputs from the trained model
* includes visualizations or examples that support evaluation of output quality
* documents key design choices and observations using Markdown cells
* A Generative AI Analysis and Ethics Report (module\_summary.pdf) that explains:
* the generative task and why it is appropriate for the chosen model
* the dataset and how it was prepared
* the model architecture and training approach
* how output quality was evaluated
* ethical considerations related to bias, misuse, or creative ownership
* limitations, risks, and potential improvements  
  This report must include in-text citations and a References section.

## Citation Expectations

In your Generative AI Analysis and Ethics Report, you must use citations when you:

* refer to generative modeling concepts or definitions (for example: GANs, VAEs, diffusion, attention mechanisms, or sampling strategies)
* justify why a particular generative model or architecture is appropriate for your task
* discuss evaluation practices for generative outputs
* address ethical considerations, bias, misuse, or intellectual property concerns

You do not need to cite your own code, generated samples, plots, or observations that come directly from your notebook outputs. Your report must end with a References section listing all sources used, such as course materials, textbooks, or official framework documentation.

## Academic Integrity Expectations

This project is designed to require authentic, individual work:

* Generated outputs must come from your own model runs and dataset.
* Your analysis must reference specific examples from your generated outputs.
* Ethical reflection must be directly tied to your model, data, and task context.
* Design decisions must be justified based on your actual implementation and results.

Generic descriptions or ethical statements not grounded in your work will not meet project expectations.

## Submission Instructions

Make sure your submission includes all of the following components.

### Notebook

* generative\_model.ipynb runs top to bottom without execution errors
* Dataset or prompt source loads correctly, and any preprocessing steps are clearly shown
* A generative model appropriate to the task (GAN, VAE, or Transformer-based generation) is fully implemented using approved course tools
* Model training or execution is demonstrated with appropriate outputs (for example, loss curves, diagnostics, or generation steps)
* Multiple generated samples are produced and displayed
* Qualitative evaluation of generated outputs is included in Markdown cells
* A short notebook summary section (4 to 6 sentences) is included

### Generative AI Analysis and Ethics Report

* Generative\_AI\_Analysis\_Report.pdf is included
* Report contains all required sections:
  + Overview
  + Dataset or Prompt Description
  + Model Design and Training Approach
  + Output Evaluation and Interpretation
  + Ethical Considerations and Responsible Use
  + Limitations and Future Improvements
  + References
* Model and training decisions are justified using the student’s own implementation and generated outputs
* At least one concrete example of generated behavior or failure case is discussed
* Ethical discussion is explicitly tied to the student’s model, data, or outputs
* In-text citations are used where required
* References section uses a consistent citation style
* At least two credible sources are cited, with at least one scholarly source

### Dataset or Prompt Source

# Environment Setup

## Local Machine Instructions

Before you begin the project, make sure your environment is set up correctly. This will help you avoid errors and ensure your generative AI notebook runs smoothly from start to finish.

1. Install Python 3.x
   You can use any recent version of Python 3 (3.9 or higher).
2. Install a notebook environment
   You may use any of the following:
   * Jupyter Notebook
   * JupyterLab
   * VS Code with the Jupyter Extension
   * Anaconda (includes Jupyter by default)
3. Install required Python libraries
   Make sure the following libraries are installed:
   * NumPy
   * Pandas
   * Matplotlib
   * Seaborn
   * PyTorch
     Depending on your chosen generative model, you may also use libraries covered in your coursework for text or image processing. All tools must come from approved course materials.
     If you are using Anaconda, many of these libraries may already be available.

## Validate Your Environment

1. Open a new Jupyter Notebook.
2. Run the following code to confirm that the required libraries import correctly:

```
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import torch
```

1. Confirm PyTorch can detect your device:

```
device = "cuda" if torch.cuda.is_available() else "cpu"
device
```

1. Load a small sample of your dataset to confirm file access works correctly:

```
df = pd.read_csv("your_dataset.csv")
df.head()
```

If the imports run without errors and the dataset loads correctly, your environment is ready.

## Create Your requirements.txt File

Before submitting your project, generate a reproducibility file from your environment:

```
pip freeze > requirements.txt
```

This file allows others to rerun your notebook using the same package versions.

## Project Instructions

### Task 1 — Define the Generative Task and Select Your Approach

For this project, you will define a generative AI task and implement a generative model using methods covered in your coursework. Selecting an appropriate generative approach and clearly framing the task are part of the assessment.

You must choose one of the following generative modeling approaches:

* Generative Adversarial Network (GAN) for image generation
* Variational Autoencoder (VAE) for image generation or representation learning
* Transformer-based generation for text or sequence data

You are not required to implement diffusion models. Diffusion models may be discussed conceptually in your written report when comparing generative approaches or addressing ethical considerations.

Clearly state the goal of your generative system and what type of content it produces.

#### Dataset or Prompt Requirements

Your dataset or prompt source must:

* Be appropriate for the chosen generative task
* Be publicly available or clearly documented
* Be appropriate for academic use
* Not be synthetic or AI-generated as a dataset
* Not be reused from any previous capstone project

Document how your data or prompt source was obtained and how it is used in your model.

### Task 2 — Load and Inspect Your Data or Prompt Source

In generative\_model.ipynb:

* Load your dataset or define your prompt source
* Display representative samples such as images, text excerpts, or sequences
* Inspect data structure, formats, and sizes
* Note any preprocessing considerations

This ensures you understand how inputs flow into the generative model.

### Task 3 — Implement and Train a Generative Model

Using approved frameworks and methods from your coursework, implement and train your generative model.

Your notebook must include:

* The full model architecture definition
* A brief Markdown explanation of key design choices
* Training code with appropriate loss functions and optimizers
* Evidence of training progress, such as loss curves or training diagnostics

The goal is a correct and stable implementation rather than perfect outputs.

### Task 4 — Generate and Evaluate Outputs

Generate sample outputs from your trained model.

Your notebook must include:

* Multiple generated examples
* A qualitative evaluation of output quality
* Discussion of strengths and failure cases

Quantitative metrics are optional where appropriate.

### Task 5 — Write a Short Notebook Summary

Add a brief Markdown section of 4 to 6 sentences summarizing:

* The generative task and model used
* Characteristics of generated outputs
* Challenges encountered during training
* Observed limitations or failure modes

This concludes your notebook.

### Task 6 — Write the Generative AI Analysis Report with Academic Citations

Create Generative\_AI\_Analysis\_Report.pdf with the following sections.

#### Overview

Explain the generative task, dataset, or prompt source, and model type used.

#### Dataset or Prompt Description

Describe the data or prompt source, its size or scope, and how it supports the generative task.

#### Model Design and Training Approach

Explain the model architecture, training setup, and key design decisions.

#### Output Evaluation and Interpretation

Discuss generated outputs, highlighting quality, variability, and limitations.

#### Ethical Considerations and Responsible Use

Identify at least one ethical concern related to bias, misuse, creative ownership, or societal impact.

#### Limitations and Future Improvements

Describe limitations of the model or data and propose realistic next steps.

#### Citation Requirements

Use citations when:

* Defining generative modeling concepts
* Justifying architectural or training decisions
* Discussing ethical or responsible-use considerations

Do not cite your own code, training logs, or generated outputs.

#### References

List all cited sources using a consistent citation style.

### Task 7 — Create requirements.txt

Generate your reproducibility file using:

```
pip freeze > requirements.txt
```

This ensures the generative AI workflow can be rerun in an identical environment.
